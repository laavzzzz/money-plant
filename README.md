# 💰 MoneyPlant

## 🌱 Stop Saving. Start Growing.

MoneyPlant is an **AI-powered gamified personal finance platform** that transforms traditional money management into an interactive growth experience.

Instead of treating personal finance as boring spreadsheets, static dashboards, and endless numbers, MoneyPlant turns financial progress into a **visual RPG-inspired ecosystem** where consistent saving, financial goals, and responsible money habits contribute to your virtual financial garden.

> 🌱 **Your money grows. Your garden grows. You grow.**

---

# 🎯 The Problem

Personal finance is often presented as a collection of:

- 📊 Spreadsheets
- 💸 Expense trackers
- 📈 Static charts
- 💰 Budget tables
- 🧾 Transaction histories

While these tools can provide information, they often fail to solve a bigger problem:

> **How do we make people consistently care about their financial habits?**

Common challenges include:

- Lack of motivation to save consistently
- Poor awareness of spending behavior
- Difficulty maintaining financial goals
- Lack of personalized financial guidance
- Financial tracking becoming repetitive
- No meaningful reward for consistency
- Difficulty visualizing long-term financial progress

MoneyPlant addresses this behavioral gap by combining **financial tracking, AI-powered insights, and gamification**.

🚀 Quick Start
Prerequisites

Make sure you have:

Node.js 18+
npm / pnpm / yarn
MongoDB Atlas account
Google Gemini API key
Git
1. Clone Repository
git clone https://github.com/laavzzzz/money-plant.git

cd money-plant
2. Install Dependencies
npm install
3. Configure Environment Variables

Create a .env.local file in the project root:

MONGODB_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_google_gemini_api_key

Use the exact environment-variable names expected by your current implementation.

4. Start Development Server
npm run dev

Open:

http://localhost:3000
🔐 Environment Variables
Variable	Description
MONGODB_URI	MongoDB Atlas connection string
GEMINI_API_KEY	Google Gemini API key

⚠️ Never commit .env.local, API keys, database credentials, or other secrets to GitHub.
